📐 新架构数据流

输入层 Mouse Move (1000Hz)
↓
视觉层 RAF Ghost Preview → CSS transform only
↓
提交层 mouseup 触发 → 单次 setBounds
↓
动画层 ease-out snap → 120ms 收尾
根因：window geometry update rate 超过 compositor 稳定同步能力
修复：将 visual feedback（Ghost CSS）与 system commit（setBounds）解耦
效果：拖拽零闪烁 + 松手平滑吸附 + 全方向一致稳定
